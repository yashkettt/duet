# Дуэт

Claude Code и ChatGPT (Codex CLI) работают по одной очереди задач. Кто делает задачу, зависит от её типа, а второй агент проверяет результат.

## Как пользоваться

1. Впиши задачи в `tasks.md`, по одной на строку:
   ```
   - [ ] code | C:\путь\к\проекту | Добавь проверку пустого email в форме
   - [ ] plan | C:\путь\к\проекту | Составь план переезда на Supabase
   ```
2. Запусти в PowerShell 7 из папки «Дуэт»:
   ```powershell
   ./duet.ps1 -DryRun   # посмотреть, кому что уйдёт
   ./duet.ps1           # выполнить всю очередь
   ./duet.ps1 -Once     # выполнить одну задачу
   ```
3. Результаты:
   - правки лежат в ветке `duet/<id>` внутри проекта, main не трогается и ничего не пушится;
   - отчёт исполнителя и ревью лежат в `notes/<id>.md`;
   - в `tasks.md` строка получает `[x]` или `[!]`, ветку и вердикт ревью.
4. Понравилось? Слей ветку сам: `git merge duet/<id>`.

## Кто что делает

| Тип | Делает | Проверяет |
|---|---|---|
| plan, text, design, review | Claude | Codex |
| code, test, fix | Codex | Claude |

Распределение меняется в `config.json` → `route`. Ревью отключается так: `"crossReview": false`. Чтобы задать модель, заполни `claude.model` или `codex.model`.

## Что нужно

- PowerShell 7 (`pwsh`), git
- Claude Code (`claude`), вход уже выполнен
- Codex CLI (`npm i -g @openai/codex`), `codex login`. Работает на тарифе ChatGPT Go, но лимиты там небольшие.

## Ограничения

- Проект должен быть git-репозиторием, и в нём не должно быть незакоммиченных изменений. Иначе задача получит `[!]`.
- Исполнитель может только править файлы. Claude не запускает команды, Codex работает в песочнице `workspace-write`. Ревьюер только читает.
- Задачи идут по одной, не параллельно.
